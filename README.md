# 隨手複製

https://z88487561.github.io/quick-ocr/

拍攝或選擇照片，在裝置上辨識繁體中文與英文，並可選取、編輯及複製辨識結果。這是一個可安裝、支援離線使用的 PWA，不需要後端服務或建置步驟。

## 使用方式

1. 在手機或電腦的瀏覽器開啟應用程式。
2. 點選「拍照辨識」使用裝置相機拍攝，或點「選照片」載入現有圖片。
3. 選擇辨識語言：繁中＋英文，或僅英文。
4. 辨識完成後，在文字欄編輯結果；點選單字或拖曳框選，可選取圖片中的部分文字。
5. 使用「全選」、「清除選取」調整選取範圍，再點「複製文字」複製內容。
6. 點「重拍」返回拍攝頁。

結果頁可用雙指或滑鼠滾輪縮放圖片，也可拖曳平移；「適合」可將圖片縮回畫面大小，「移動」可切換拖曳平移模式。

## 電腦版功能

- **貼上／拖放**：按 `Ctrl+V` 貼上剪貼簿圖片（例如截圖），或把圖片檔拖進視窗即可辨識。
- **螢幕擷取辨識**：首頁的「擷取螢幕」會請你選擇螢幕、視窗或分頁，擷取一張畫面後可拖曳框選區域（Enter 辨識、Esc 取消），或按「整張辨識」。結果頁的「重新擷取」可再擷取一次。也可用系統截圖（Windows：`Win+Shift+S`，macOS：`Cmd+Ctrl+Shift+4`）截好後直接 `Ctrl+V` 貼上。
- **雙欄版面**：視窗寬度 ≥ 900px 時，左邊圖片、右邊文字。
- **保留原圖、框選重辨**：原圖（最長邊 4096px）會保留；拖曳框選一塊區域後按「重辨框選區」，會從原圖裁切、放大、增強後單獨重新辨識，並取代該區舊結果。
- **影像增強**：灰階＋對比拉伸，深色背景自動反相；小圖（最長邊 < 1200px）會先放大 2 倍。電腦的辨識尺寸上限為 2400px（手機 1600px）。
- **低信心字詞**以橘色虛線標示，不再被默默丟掉。
- **複製選項**：保留換行／合併成一段、去除中文間空格、中文標點修正（設定會記住）。
- **快捷鍵**（結果頁）：`Ctrl+A` 全選、`Ctrl+C` 複製、`Esc` 清除選取。

## 相機說明

「拍照辨識」會在頁面內開啟即時預覽（`getUserMedia`），預設使用後鏡頭，不必離開 App：

- 預覽畫面上方的下拉選單可切換鏡頭，選擇會存在 `localStorage`，下次自動套用；若記住的鏡頭已不存在會自動改回預設後鏡頭。
- 若瀏覽器支援縮放（`zoom`），會出現縮放滑桿，且依每顆鏡頭分別記住。
- 按快門時優先用 `ImageCapture.takePhoto()` 取得靜態照（限制在約 2560px），不支援時改擷取預覽畫面。
- 若相機權限被拒或無法開啟即時預覽，會改用系統相機（`capture="environment"`）。也可用「選照片」載入現有圖片。
- 辨識引擎會在閒置時預先載入（預熱），拍完照可直接辨識；辨識前影像最長邊縮至 1600px。
- 離開預覽或切到背景時會自動關閉相機。

## 離線與更新

- Tesseract.js、核心檔案及繁中／英文語言資料存放在 `vendor/`，Service Worker 會在首次載入時快取所需資源；快取完成後可離線辨識。
- 更新程式後，請將 `sw.js` 中的 `VERSION` 加 1。已安裝的使用者會看到更新提示，按「立即更新」套用新版本。
- 請確認部署時一併上傳完整的 `vendor/` 資料夾。

## 安裝

- 支援安裝提示的瀏覽器可使用「安裝 App」。
- iPhone／iPad 可在 Safari 點「分享」→「加入主畫面」。
